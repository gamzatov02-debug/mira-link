# Аудит текущего проекта · 23 сентября 2026

Предыдущая запись об отсутствии репозитория устарела. Изменения выполняются внутри `mira-link`, без второго проекта.

## Обнаружено до изменений
- React 19, TypeScript, Vinext / App Router, Vite, npm и существующий package-lock.
- Главная `/`: сайт в зелёно-золотой палитре, ссылки на отсутствовавшие страницы демо.
- `lib/domain/model.ts`, `engine.ts`, `selectors.ts`, `seed.ts`: модель Session, заказы, части счёта, платежи, бонусы, callbacks.
- `lib/store.ts`: localStorage, BroadcastChannel, storage events, Web Locks для последовательной обработки команд из вкладок.
- `lib/adapters.ts`: демо-адаптеры POS, оплаты и партнёрских сервисов.
- `components/mira.tsx`: брендовые примитивы, диалог, переключатель, статусы; `components/ui` — библиотека компонентов.
- `app/globals.css`: существующая палитра и стили. Они сохранены и расширены.
- `docs/MASTER_SPEC.md`: единственный найденный документ с бизнес-логикой. Отдельных Business Specification, последних решений владельца, MIRA_LINK_UI_TZ, PDF/DOCX нет.
- Оригинального логотипа нет. В существующем Logo стоит `ASSET REQUIRED`; новая монограмма не создавалась.
- Изображения: внешнее фото на главной; локально только стандартные SVG. Тестов до изменений нет.

## Найденные расхождения
- Нет `/demo`, Guest, Waiter, Admin, Full Cycle; основной пользовательский цикл недоступен.
- Ошибка TypeScript в assertion helper.
- Равное разделение последовательно делило уменьшающийся остаток на исходное число гостей; не учитывались резервирования.
- У наличной оплаты не создавалась запись обязательства комиссии заведения.
- Нет автоматических проверок инвариантов через unit / E2E.
- Условия финансовых акций / промокодов отсутствуют; нельзя выдумывать процент скидки.

## Реализация
Существующее domain-ядро и shared store сохранены. Добавлены маршруты и интерфейсы, связанные с командами ядра. Исправлены расчёты равных частей, денежный ноль и учёт комиссии наличных. Партнёрская аренда и доставка включены в общий state, отдельно от Session. Reset синхронизирован между вкладками.
